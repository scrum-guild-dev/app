# 検査の選択と再利用

必要な検査は [acceptance.md](acceptance.md) と CLAUDE.md のコマンドから選ぶ。実装、受け取り、done-check の工程が移っただけでは再実行しない。

## 記録するもの

- 作業ディレクトリ、コマンドと対象、開始・終了時刻、終了コード、実行ログの保存先
- 検査の入力状態。HEAD だけでなく、未コミット・新規ファイルを含む入力ファイルの内容ハッシュ、依存の状態、Node・pnpm の版、検査に使った設定と非秘密の環境条件
- 成功・失敗と未検証の項目。秘密情報や環境変数の全件出力は記録しない

記録はスクラッチのファイルに置き、委譲先から進行役、done-check へ引き継ぐ。現在の状態と比較できる根拠がない結果は再利用しない。全体検査なら設定・依存と追跡対象のソース全体、新規ファイルも入力に含める。

## 再利用できる条件

進行役が実行ログと終了コードを読み、成功した検査の入力状態・対象・環境が現在と一致すると確かめた場合だけ再利用する。「通った」という報告だけや HEAD の一致だけでは足りない。
実行中に入力が変わった検査、ログの無い検査、別のワークツリーや以前のセッションの結果は使わない。
コミットを作っただけで内容が同じなら再実行は不要。ローカルの記録は CI の成功や独立レビューの代わりにしない。

修正後は影響する検査だけ再実行する。共有コード、依存、検査・ビルド設定、実行環境が変わった場合や影響範囲を絞れない場合は全体の必要な検査をやり直す。動作確認も同じ条件で再利用し、未実施は未検証と報告する。
